# eting.cn
a simple web-based audio player designed for playing your local audio files.
# function
people can play any audio file from his own PC or phone via this very website https://eting.cn/index.php
# deploy your own website and your own player
you can just copy index.php into your web host directory, then done
# what if I don't have a PHP hosting?
Simple, rename it to index.html, and run it...done
# what if I am not only want it can play my local audio file, but also I can put my files on line?
then u need a PHP enabled webhosting, and u also need copy that very audio-api.php into your hosting directory, and u also need create a folder named /audio and put some audio file(s) into the audio, then done
